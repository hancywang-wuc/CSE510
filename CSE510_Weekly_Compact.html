CSE510 — Operating System · Weekly Outline

Fall 2026 · Whitewater University of California · Compact Reference Table

Alt OS option: The alternative operating system portion of each weekly assignment is completed on a familiar Mac or Windows laptop. Follow the corresponding brief operation in that week's Alt-OS item and submit screenshots.

Week Topic Weekly Assignment
W1 System Anatomy — Understanding the Ubuntu Desktop
Log in to your school-provided Ubuntu server or any OS like iPhone/Android phone. Using only the mouse/Tap/Touchscreen, customize the desktop/home screen dock to include any apps related to Files app, Firefox browser, Software Centre, System Settings, System Monitor, and Text Editor. Screenshot the customized dock and the full desktop. Submit to Moodle. This desktop configuration will be used as the starting point for every session that follows.
Alt-OSUsing alternative OS to show case the similar concepts apply to all future weekly assignments.
W2 File Management & Folder Permissions
Using the Files app, create a folder structure inside the Home directory with three subfolders: Server Projects, Shared Files, and Private Config. Right-click each folder, open Properties, go to the Permissions tab, and set appropriate access levels for each — Private Config should be owner-only. Screenshot the folder structure in the Files app and the permission settings for each folder. Submit to Moodle.
Hands-onPermission test: In System Settings, create a second standard user account. Log in as that user and attempt to open the Private Config folder. Screenshot the access denied result. Log back in as the main administrator account. Write one sentence explaining why restricting folder access is an essential operating system function.
Alt-OSAlternative OS option — On an iPhone, use the Files app to create folders under On My iPhone and use the Share sheet to see how access is limited between apps. On Android, use the Files app to create folders and check Settings > Apps > Permissions to see how each app's storage access is individually restricted, mirroring the concept of folder permissions.
W3 Monitoring System Resources — CPU, Memory & Running Processes
Open the System Monitor. Identify the three processes consuming the most CPU and the three consuming the most memory. Screenshot the System Monitor with those processes visible and their resource usage readable. Identify at least one non-essential background process and end it using the End Process button. Screenshot the updated process list after closing it. Submit both screenshots to Moodle.
Hands-onResource stress test: Open ten browser tabs in Firefox simultaneously and observe how the CPU and memory graphs respond in the System Monitor. Screenshot the graphs at peak usage, then close all tabs and screenshot them again once they settle. Write one sentence explaining the relationship between the number of active applications and the server's available resources.
Alt-OSAlternative OS option — On an iPhone, check Settings > Battery and Settings > General > iPhone Storage to see which apps use the most battery and storage, then swipe up on an app in the App Switcher to force-close it. On Android, check Settings > Battery and Settings > Storage (or Device Care) to identify the top resource-consuming apps, then force-stop one from Settings > Apps.
W4 Installing & Removing Software Using the Software/App Centre
Open the Ubuntu Software Centre. Install a visual text editor (such as Gedit or Kate) and a file archive manager (such as File Roller). Confirm both applications appear in the application menu and open correctly. Then uninstall one of them through the Software Centre. Screenshot the Software Centre showing the installation of each app and the uninstall confirmation. Submit to Moodle.
Hands-onSoftware removal test: After uninstalling one application, check the application menu to confirm it no longer appears. Try to open it from the Files app if any leftover files remain. Screenshot the result. Write one sentence explaining why the operating system needs to cleanly remove all associated files when an application is uninstalled.
Alt-OSAlternative OS option — On an iPhone, use the App Store to install an app, then press and hold the icon and choose Remove App to uninstall it. On Android, use the Google Play Store to install an app, then uninstall it from Settings > Apps or directly from the Play Store listing, observing the same install/uninstall cycle as the Ubuntu Software Centre.
W5 Exploring the System Settings — The Operating System Control Panel
Open System Settings and complete the following configurations using only the mouse: set the display to the highest available resolution, disable automatic screen lock in Privacy settings, set the power profile to Performance, and confirm the correct region and language settings. Screenshot each settings panel after making the change. Submit all screenshots to Moodle.
Hands-onSettings impact test: In System Settings, temporarily enable automatic screen lock with a 1-minute timeout. Wait for the screen to lock, then unlock it. Then disable automatic screen lock again. Screenshot the lock screen and the disabled setting. Write one sentence explaining why an unattended server should not automatically lock its screen during active use.
Alt-OSAlternative OS option — On an iPhone or Android phone, open the Settings app and work through the equivalent categories: Display & Brightness, Battery, Default Apps, Accessibility, Language & Region, and Privacy. Screenshot each panel the same way as the Ubuntu System Settings exercise.
W6 Network Configuration & Firewall Management
Open System Settings and navigate to the Network panel. Record the server's current IP address and screenshot the network configuration screen. Install the GUFW graphical firewall manager from the Software Centre. Enable the firewall and add rules to allow web traffic (HTTP and HTTPS). Screenshot the firewall panel with the rules active and the firewall enabled. Submit to Moodle.
Alt-OSAlternative OS option — On an iPhone, go to Settings > Wi-Fi and tap the (i) next to your network to view the IP address, then explore Screen Time > Content & Privacy Restrictions as a simplified parallel to firewall rules. On Android, go to Settings > Network & Internet > Wi-Fi to view the IP address, then explore Digital Wellbeing or a firewall app such as NetGuard to allow or block traffic by app.
W7 User Account Management
Open System Settings and navigate to the Users panel. Create an administrator account named Server Admin and a standard account named Server User. Set a secure password for each. Screenshot the Users panel showing both accounts with their respective privilege levels visible. Submit to Moodle.
Hands-onPrivilege comparison: Log in as the Server User standard account. Attempt to open System Settings and navigate to the Users panel to create a new account. Screenshot the result — whether it is blocked or requires a password. Log back in as the administrator. Write one sentence explaining why the operating system enforces different permission levels for different user accounts.
Alt-OSAlternative OS option — iPhones do not support separate user accounts, so this concept is best explored on Android: go to Settings > System > Multiple Users, add a new restricted user, and compare what that account can and cannot access versus the primary administrator account. iPhone users can approximate this using Screen Time > Family Sharing to review parental and restricted access controls.
W8 Enabling the Web Server & Hosting a Local Web Page
Install Apache from the Ubuntu Software/App Centre or through embedded python module. Open the Files app and navigate to the folder want to publish (e.g. /var/www/html/ for Apache). Place Claude's generated HTML file into the folder. Open Firefox and navigate to http://localhost to confirm the web page loads. Screenshot the browser showing the live page and the System Monitor showing the Apache/Python process running. Submit to Moodle.
Hands-onWeb server on/off test: Use the System Monitor to find and end the Apache process. Refresh the browser and screenshot the result — the page should no longer load. Restart Apache using the Software Centre's manage application feature. Confirm the page loads again. Write one sentence explaining the relationship between a running operating system process and a service that users can access.
Alt-OSAlternative OS option — Phone operating systems sandbox apps and do not allow a true self-hosted web server the way Ubuntu does. Students without access to the Ubuntu server may instead install a simple local HTTP server app from the Play Store to serve a basic page on the local network, or review the concept with Claude/ChatGPT and screenshot the app's running state as a substitute for the live Apache demonstration.
W9 Introduction to Databases — Creating & Managing Data Visually
Install DB Browser for SQLite from the Ubuntu Software Centre. Create a new database file named server_data.db. Use the visual table designer to create a table named User Accounts with columns for Username (text), Role (text), Email (text), and Date Created (text). Add at least five rows of sample data using the graphical row editor. Screenshot the completed table with all rows visible. Submit to Moodle.
Alt-OSAlternative OS option — On an iPhone or Android phone, install a lightweight SQLite database app from the App Store or Play Store (search “SQLite viewer” or “SQLite editor”) to create a table and add sample rows, mirroring the DB Browser exercise. Alternatively, use the Numbers or Google Sheets app to build a structured table as a simplified stand-in for rows and columns.
W10 Expanding the Database — Adding Tables & Filtering Data
Open DB Browser for SQLite and add a second table to the server_data.db database named Activity Log with columns for Event ID, Username, Action, and Timestamp. Add at least five rows of sample log entries. Use the visual filter controls to display only the entries belonging to one specific username. Screenshot the filtered result and the schema diagram showing both tables. Submit to Moodle.
Hands-onData integrity test: In DB Browser, attempt to add a new row to the Activity Log table while leaving the Username column empty. Observe what happens. Then use the table designer to set the Username column as required (NOT NULL). Attempt the empty row again and screenshot the result. Write one sentence explaining why preventing empty required fields is important for maintaining reliable server records.
Alt-OSAlternative OS option — Using the same mobile SQLite app from Week 9 (or a spreadsheet app), add a second table or sheet, enter sample log-style data, and use the app's built-in search or filter feature to isolate records belonging to one user, mirroring the filtering exercise in DB Browser.
W11 Backup & Data Protection
Open the Backups application. Configure it to back up the Home directory and Server Projects folder to an external drive or secondary storage location. Schedule automatic backups daily. Run a manual backup immediately and confirm the backup files appear in the destination. Delete one file from the Server Projects folder, then use the Backups app to restore it. Screenshot the backup configuration, the successful backup, and the restored file. Submit to Moodle.
Alt-OSAlternative OS option — On an iPhone, confirm iCloud Backup is enabled in Settings > [Your Name] > iCloud > iCloud Backup, run a manual backup, delete a note or photo, and restore it from Recently Deleted. On Android, confirm Google backup is enabled in Settings > System > Backup, run a manual backup, then restore a deleted item from Google Photos Trash or the relevant app's recycle bin.
W12 Creating a Full System Image
Open the Disks utility. Select the main system drive. Use the gear icon menu to create a partition image and save it to an external drive. Confirm the image file appears on the external drive in the Files app. Screenshot the Disks utility during the image creation process and the resulting image file with its file size visible. Submit to Moodle.
Hands-onImage size analysis: Right-click the system image file in the Files app and view its properties to find its size. Compare this to the total size of just the Home directory. Ask Claude to explain what the difference in size tells you about what a system image contains versus a file backup. Write one sentence summarizing the key difference.
Alt-OSAlternative OS option — On an iPhone, connect to a computer and use Finder (or iTunes) to create a full encrypted backup, which functions like a system image. On Android, use the manufacturer's backup tool or Google's full device backup (Settings > System > Backup) to capture a complete device snapshot, then compare its size to a single folder's size as in the Week 12 experiment.
W13 Restoring from a System Image — Server Deployment
Open the Disks utility and attach a secondary virtual disk. Use the Restore Partition Image option to deploy the Week 12 system image onto the new disk. Boot from the restored disk and confirm the following are all intact: the desktop dock configuration from Week 1, the folder structure from Week 2, the Apache web page from Week 8, and the database from Week 9. Screenshot all four confirmations on the restored disk. Submit to Moodle.
Alt-OSAlternative OS option — If a spare or reset iPhone/Android device is available, restore the Week 12 full-device backup onto it and confirm installed apps, settings, and files return successfully, mirroring the Disks utility restore exercise. If no spare device is available, discuss with Claude/ChatGPT what would be restored and screenshot the backup's file list as evidence of its scope.
W14 Full Ubuntu Server Installation Using the Visual Installer
Using the school-provided installation media, complete a full Ubuntu installation on a designated practice disk or virtual machine. Work through every installer screen using only the mouse. After installation, confirm the system boots to the desktop successfully. Screenshot each major installer screen — language selection, time zone configuration, disk setup, and user account creation — as well as the final working desktop after installation. Submit all screenshots to Moodle.
Alt-OSAlternative OS option — With Claude or ChatGPT guiding each step, perform a full factory reset and fresh setup on a personal iPhone or Android phone: language and region selection, Wi-Fi connection, account sign-in, and initial configuration. Screenshot each major setup screen just as with the Ubuntu visual installer. This is optional and only recommended if a spare or resettable device is available.
W15 Final Review / Makeup & Q&A Session
Final Review/makeup for the weekly submissions and Q/A Session The alternative OS (Mac/Windows) options in Weeks 1-14 assignments will be reviewed. All the previous Week 1-14 compiles the capstone project and will be reviewed and discussed live in class and provide Q/A session to support the students altogether.
